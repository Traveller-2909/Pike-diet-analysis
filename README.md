Code and data used in the manuscript "Eating with a grain of salt: Trade-offs between habitat use and individual foraging specialisation drive growth across ecotypes of a freshwater piscivore (pike, Esox lucius) inhabiting brackish habitats"
Contents:
Analysis.Rproj - R project file
Analysis_cleanup.Rmd - Markdown generating the files and tables needed for the main Analysis
Analysis_main.Rmd - Markdown containing the main code for producing the results and figures presented in the paper
funcs.R - Script containing helper functions used in the main code
